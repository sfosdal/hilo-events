# Hilo Events → Big Island Events

hilo.here.events was Hilo Events' host for one day, 2026-10-25. That night the
Kona and Hilo calendars merged into one site for the whole of Hawaiʻi Island,
**https://bigisland.here.events/** (repo sfosdal/bigisland-events), and this
repo became a redirect stub: `index.html` and `404.html` send every path on
to the new host (the `?f=` share code is dropped — the merged site's registry
is new). Nothing is built here any more; the workflow publishes the two pages
on push. The old build is in this repo's history, the archive branch too.
